# Complete supplementary data

Use FILE_INDEX.csv to find scientific content and its current reading-table links. D001.csv and subsequent files contain aggregate results, not participant records. Dataset numbers are not table numbers. DATA_DICTIONARY.csv gives field definitions, units/context, and missing-value meaning. VALUE_CODES.csv explains model, outcome, error, and threshold codes. Numeric values retain source precision; display strings are accompanied by numeric estimates/interval endpoints where available. Percentages are stored as fractions.

All formal 34-protein pathology and 68/136/204 cognitive families, all 9/33/42 conditioning hypotheses, and their detailed effects are retained. The fourteen-protein interpretation subset does not trigger new primary correction. Computed P and P entered into correction are distinct: unqualified tests retain correction P=1 and stay in the family. Such a 1 is not measured evidence of no association or non-equivalence. The reading workbooks instead mark the affected inference unavailable. CST3 memory change is the failed cognitive design. Baseline memory has no year denominator. Pathology residual-SD scaling differs from the original fixed protein-SD scaling for cognition.

Supporting relative-response candidates (PDGFRB/NPTX1/KLK6) differ from the conditioning trio (NPTX2/TAFA5/TIMP3). Historical clinical families 6/26/32 do not replace the final 68/136/204 families. The 33-protein relative-amyloid-PET family differs from the 33-test conditioning family. Supporting/exploratory analyses remain indexed for transparency; they are not independent external validation.

NULISA detection is inapplicable to SomaScan/TMT: non-NULISA default values in the original background audit were masked as unavailable in this data release. Four-assay ratio estimability, positive cross-covariance-CI requirements, and operational-equivalence eligibility are separate from tetrad calibration. New flags describe these distinctions; original test P/q values are unchanged. The five direct-MRM confidence intervals are the original two-sided t(4) intervals; direct P values are one-sided positive.

Simulation outputs are conditional on frozen designs. Noise draws are reused across mean patterns and thresholds, not independent replications. BY first-step thresholds are sufficient cutoffs, not actual rank-adaptive family power. Working alternatives are not clinical MCIDs. Additional independent-panel scenarios are hypothetical, not new cohorts.

New data descriptions summarize the original paired index, p-tau reference, and cognitive reference (571/560/557). Diagnosis is descriptive: nearest valid nonconflicting record within ±90 days, with on/before-CSF ties then original row order. These summaries did not modify any association sample or refit any model. Available n and sample SD/IQR definitions are documented in reading Table S1.
