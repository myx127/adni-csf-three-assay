**Supplementary Figure S10. Conditional power for detecting shared associations with annual memory change.**

Power was evaluated for the paired test of memory associations in the same direction across all three assays. Simulations retained each protein’s observed participants, measurements, covariates, laboratory batches and cognitive follow-up pattern, including p-tau181 adjustment. Effect magnitudes were assigned simulation values, expressed as ADNI-MEM score units/year per fixed assay-specific protein residual SD (Supplementary Methods Section 6).

(A, B) The true standardized coefficients in all three assays were set to the same magnitude, 0.02, 0.05 or 0.10, with a common positive or negative sign. Each cell reports the minimum simulated rejection percentage across five error structures and both signs. Panel A uses the nominal threshold P ≤ 0.05; panel B uses the BY first-step threshold for 68 tests, approximately 0.000153057. Both panels share a 0–100% color scale. Zero denotes no observed rejections in the selected simulation cell; positive values below 0.01% are labeled <0.01. Shaded protein labels identify the 14 proteins with shared p-tau181 associations, without restricting the set of comparisons. Protein-specific memory analysis samples ranged from 342 to 557 participants. †CST3 did not meet the prespecified memory calibration criteria (Supplementary Fig. S7); dashes indicate unavailable power interpretation, rather than zero power.

(C, D) The equal-effect scenario of 0.05 in all assays is compared with scenarios in which the indicated assay has an absolute coefficient of 0.02 and the other two retain 0.05. All three coefficients have the same sign. For each configuration and threshold, a dot represents the minimum simulated rejection percentage over the five error structures and both signs for one of the 33 qualified protein designs. Rose bars show the median across these designs. Vertical offsets separate protein markers within categories; horizontal values are unchanged. These panels use different horizontal ranges: 0–75% at the nominal threshold and 0–1.2% at the BY first-step threshold. The distributions describe protein-specific designs involving overlapping participants, .

Five error structures comprised independent Gaussian errors; serial correlation with participant slopes; p-tau-dependent heteroscedasticity; technical age slopes; and normalized Student t5 errors with technical slopes. Each design/error-structure cell used 100,000 independent noise draws, reused across effect patterns and thresholds. Plotted minima are descriptive summaries of the examined finite scenarios. Complete cell-specific results and their Wilson Monte Carlo bounds are provided in the accompanying data; those bounds are not simultaneous confidence intervals for the selected minimum.

The BY first-step cutoff was based on 68 comparisons: two tests for each of 34 proteins, including CST3. This correction scope was retained for the 14 proteins with shared p-tau181 associations and the 33 proteins meeting memory calibration criteria. Panels B and D report detection probabilities at this fixed sufficient threshold for BY rejection. Details are provided in Supplementary Table S13 and Supplementary Methods Section 6 and Appendix B.

Abbreviations: ADNI-MEM, Alzheimer’s Disease Neuroimaging Initiative memory composite; BY, Benjamini–Yekutieli; SD, standard deviation.
