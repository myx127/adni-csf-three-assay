**Supplementary Figure S15. Illustrative simulations of measurement error and p-tau181 adjustment.**

(A) A hypothetical model in which all three assays measure the same common protein signal L. Independent standard normal variables P, representing a p-tau181 analogue, and U, representing another common component, generate L = 0.8P + U and an outcome Y = −0.06P + 0.10U + η. The outcome error η has SD 0.2. Each assay has a loading of one on L and additive Gaussian measurement error with variance ψ. Measurement errors are mutually independent and independent of P, U and η. Arrows and labels specify the illustrative data-generating model.

(B) Population coefficients (open circles) and ordinary least-squares estimates from one sample of 200,000 synthetic participants (crosses), before and after adjustment for P. Assumed error variances are 3.0 for NULISA, 0.1 for SomaScan and 4.0 for TMT-MS. The closely aligned symbols show agreement between the analytical model and synthetic estimates. The error variances were assigned for illustration. Coefficients γ are expressed in synthetic outcome units per preadjustment SD of the corresponding assay; the same SD is retained after adjustment. This is a separate example from the grid in C and D, which does not include an error variance of 3.0.

(C, D) Population contrasts in standardized outcome associations, defined as the comparison assay minus the reference assay, without and with P adjustment. Rows and columns vary the reference and comparison error variances over 0.1, 0.5, 1, 2 and 4. Both panels use the same symmetric color scale from −0.075 to 0.075; displayed values are rounded to three decimals. The matrices apply to either SomaScan minus NULISA or TMT-MS minus NULISA, with NULISA as the reference. The full three-assay grid contains 125 combinations, but each pairwise contrast has 25 distinct settings, each repeated for five values of the unused third assay’s error variance. Both contrast types yield the same matrices after relabeling the comparison assay; these are analytical population values, without sampling variation.

Equal error variances produced zero contrasts on the diagonals. In the specified model, unequal variances produced between-assay differences before adjustment and larger absolute differences after adjustment, despite a common signal and equal loadings. Model parameters were assigned for illustration. Complete numerical results are supplied with this figure; equations and the synthetic check are described in Supplementary Methods Appendix D.3.

Abbreviations: ADNI, Alzheimer’s Disease Neuroimaging Initiative; SD, standard deviation.
