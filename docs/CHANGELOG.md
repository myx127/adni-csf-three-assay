# Version 1.0.0 preparation

21 November 2026: local software package prepared for review and supplementary submission. No public repository or archival DOI has been issued by this preparation.

Original analysis and drawing programs are preserved byte-for-byte. The reusable numerical kernels change only the data-dependent configuration import; all function bodies are identical to their original stage sources. The English plotting wrapper creates output directories and supplies a fallback font when the original operating-system font is unavailable.

The private-workspace preparation utility also corrects a stage-directory lookup in stage 9. That historical program ran before stages 10-12 existed and selected stage 1 with a prefix-only match. A fresh complete workspace instead uses a number-boundary match, so stage 10 cannot be mistaken for stage 1. This adjustment affects source discovery, not a numerical function. The frozen original stage 9 program remains unchanged in this archive.

21 November 2026: the author authorized public release in the independent GitHub repository. Original numerical programs and published aggregates are unchanged.
