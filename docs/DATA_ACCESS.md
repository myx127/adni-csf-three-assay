# Data access

Obtain authorized access through the [ADNI Image and Data Archive](https://ida.loni.usc.edu/). Use the release names and hashes in `metadata/input_files.csv`. The core inputs are NULISA CSF protein measurements, SomaScan post-QC matrix and analyte annotation, TMT-MS archive, separately measured Roche Elecsys CSF p-tau181, cognition, demographics, education/APOE, and the documented additional biomarker and targeted-proteomics releases.

Raw files, subject/date crosswalks, visit records, private model templates, follow-up schedules, individual background scores and transformed participant-level protein matrices are intentionally absent. Approval to access ADNI data does not authorize redistribution through a software repository. The public package contains code and previously prepared aggregate results only.

Access and sharing requirements are described in the [ADNI Data Use Agreement](https://adni.loni.usc.edu/wp-content/themes/adni_2023/documents/ADNI_Data_Use_Agreement.pdf). No ADNI credentials are needed for the synthetic example, aggregate checks or figure rendering.
