# 第10阶段：AD病理背景下的跨检测临床关联与五年认知进展分析

分析日期：2026-10-29。此前9阶段结果和候选选择已知；本阶段在首次读取认知连续值、连接蛋白与新临床结局之前固定规则。它是发现后的临床延伸，不能称为独立重复、发现前全研究预注册或临床可用预测模型。

## 科学问题与固定对象

核心候选固定为原主分析的NPTX1、KLK6、PDGFRB。逐蛋白三检测采用同一批病例、相同结局和协变量，直接比较可比尺度上的关联，不以一个显著另一个不显著判断差异。

主要问题：三检测是否与五年记忆变化有同向关联；其临床关联强度是否不同。次级问题：基线记忆、执行功能变化、独立淀粉样PET，以及淀粉样背景对记忆关联的效应修饰。APOE修饰仅在预先指定的PDGFRB开展。没有构造个体共识/偏离潜变量评分。

## 数据口径

- 蛋白沿用Stage5 NPQ、log2RFU、log2样本/GIS、缺失和原逐蛋白完整病例。
- 原同日Elecsys pTau181 log2全局标准化沿用；年龄、性别、教育、APOE及三检测技术因子、Elecsys批次共同调整。
- ADNI_MEM/ADNI_EF固定UWNPSYCHSUM 2023版本。基线为距采样±90天内最近有效日，等距取采样前，再按源行。随访为采样后>90天、晚于所选基线、≤5×365.25天。相同RID/日期有冲突时排除该结局该日，不按关联选择。
- 主纵向样本只要求基线及至少1次随访；高信息量（至少2次随访且跨度≥2年）是固定敏感性。
- PET取±90天、源采集日和Stage4已核实的QC/重处理优先；跨示踪剂用Centiloid并调整示踪剂。A状态用发布类别作描述，效应修饰主变量为连续CL/50。同期tauPET不分析。

## 纵向模型与可比尺度

主要模型为受试者固定截距、时间×蛋白、时间×全部共同协变量/技术因子的线性纵向模型。固定截距吸收个体水平差异；采用每人中心化时间的精确充分统计量计算，等价于按s_tt加权的观测线性趋势回归，不把单人趋势当成无误差结局或潜变量评分。

主估计是给定所观察随访安排下的线性变化关联，并非个体未来风险预测。五年不要求每人随访满五年。三年窗口、等权个体、高信息量、基线记忆条件模型及共同二次时间项为敏感性；二次时间模型用每人两个正交时间分量精确约化。

蛋白单位固定为原逐蛋白完整临床队列中、剔除共同人口学和技术因子（不含pTau及新结局）后的残差SD。三个模型、PET子集及敏感性保持该单位，标准化不按新结局挑选。比较标准化关联时联合传播系数及该SD估计的不确定度；零关联检验使用原始尺度系数，避免标准化改变零假设。

各人聚合估计方程保留纵向重复的共同影响。方差按原三个技术轴的单向CR1矩阵求和，不是CGM或CR2；三检测共同结局的相关性通过联合影响函数保留。新设计须独立进行有限情景校准，不能借用pTau分析的校准结论。最小门槛为n80、保守个体信息df40、三个实际病例技术轴各≥6簇，且目标参数可估计。

## 固定检验家族

主要家族6项：3蛋白×（三检测同向记忆进展关联；三检测标准化关联相等的2df差异检验），BY6。

次级26项：基线记忆6、执行功能五年变化6、淀粉样CL关联6、淀粉样×蛋白对记忆进展修饰的3df全零及2df检测间差异6；PDGFRB的APOE×蛋白修饰全零及检测间差异2。次级BY26。主次全部32项的BY32作为全问题校正敏感性。不合格或校准不通过的检验置P=1，家族大小不变。

同向P取两方向IUT：p+=max单侧P、p-=max相反单侧P，p_same=min(1,2min(p+,p-))。相等零假设是标准化观测关联相等，不是分子等效；未拒绝不能判可互换。

连续淀粉样/APOE交互模型包含蛋白主效应、修饰变量及其与全部共同斜率协变量/技术因子的交互，防止以简化技术设计制造效应。所有结果均条件于规定协变量，不作中介或因果解释。

## 固定敏感性

主记忆分支另做不加pTau、原值pTau、三年窗口、高信息量、个体等权、Elecsys Batch9、基线记忆条件、共同二次时间、PET子集加CL主效应。保持病例规则及曝光单位；每个分支固定BY6仅作诊断，不重选主分析或改变全问题家族。基线记忆条件模型可能受共同基线测量误差/回归均值影响，不能取代主模型。

## 校准、功效与停止条件

正式16个三检测设计×5个DGP×20000独立噪声重复；敏感性最多27设计×5×6000。DGP覆盖独立访视噪声、AR1访视相关及个体随机斜率、pTau异方差、三技术轴年龄随机斜率、t5及技术斜率。使用实际时间/缺失/蛋白/技术设计；此为条件性有限情景，不证明所有误差结构或信息性失访均被控制。

同一噪声重复用于多个固定均值模式：全零、标准化三系数相同的非零、一个/两个零而其他非零、混合方向、平衡同向和检测间差异功效。通过线性约束构造真实边际系数；不把模式评价次数计为独立噪声数。

资格要求：相关零假设所有情景Wilson95上界≤0.06、失败比例≤0.005；正式设计另核查BY6/BY32第一步充分阈值的小尾部（Wilson上界不超过相应阈值）。敏感性只要求BY6尾部。未通过则仅描述，不更换估计器追求通过。

功效采用工作效应，不称既定临床最小重要差异，也不根据观测效应算事后功效。记录完整种子、设计摘要、逐次P值及独立数学/数值复核。失访与时间权重贡献另审计，不声称敏感性已解决非随机失访。
